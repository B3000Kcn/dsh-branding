# 品牌设置（DSH Web）

独立插件 **dsh-branding**，在「设置 → 品牌设置」配置 favicon、日夜横幅和标签页应用名称。包名、Host 条目、配置命名空间、客户端模块及样式标识均为独立的 `dsh-branding`，不依赖其他第三方插件。

## 0.1.2：主界面横幅

输入框上方的原生品牌图样和标题改用当前日夜模式对应的侧栏横幅，无须再次上传。在日间／夜间横幅原有侧栏操作下方，分别新增「主界面横幅缩放」和「主界面左右位移」：10% 步进，范围 10%–300%；5px 步进，范围 -200px–+200px，默认 100%／0px，并提供重置。主界面和侧栏分别保存缩放及位置，调整一处不会移动另一处。

主界面横幅默认在最多 480px 宽、80px 高的区域完整显示，保持比例并跟随可用宽度；放大时增加容器高度，横向超出部分裁切，平移距离不随缩放倍数增加。未设置当前模式图片、清空、加载失败或停用时恢复原生品牌图样与标题。

非 VCP 预设显示横幅；VCP Agent 选择区域出现时仍由现有 Agent 插件接管，其尺寸和点击行为不变。实现替换的是原生品牌插槽，不读取或修改预设：如果 VCP 尚未显示 Agent、仍露出原生品牌区域，该占位区域同样使用横幅。多会话各自保留 Agent 区域，不使用全局当前会话来决定所有页面的显示。

本次经用户批准，主界面横幅及独立步进控件已纳入 0.1.2 客户端和安装包。侧栏同时补齐图片旧回调保护，日夜切换回同一图片时，旧图片迟到的错误不再撤销新横幅；主界面同图重试成功后清除旧错误提示。旧版安装包保留。

## 功能

- favicon、日间横幅、夜间横幅分别上传；未设置时保留 dsh 原图，不借用另一个模式的横幅。支持 PNG、JPEG、WebP、GIF、SVG、ICO，单张最多 512 KiB。
- 自定义 favicon 同时用作侧栏品牌标记，替换收起后窄侧栏顶部的鲸鱼；没有完整横幅时，展开侧栏的小标记也使用它。沿用宿主提供的图标尺寸和展开按钮，悬停时仍显示原生展开提示。清空 favicon 或停用插件后恢复原图。
- 横幅跟随 dsh 实际明暗主题。默认扣除侧栏按钮所在一侧的占位后，在剩余区域居中；独立上方开关条不占用品牌行。
- 日夜各自提供「− / ＋」缩放，每次 10%，范围 10%–300%，可重置为 100%。左右「← / →」位移每次 5px，范围 -200px–+200px，可重置居中。位移不乘缩放倍数；超出侧栏的图像会裁切。
- 「标签页应用名称」在 dsh 自身所有网页标题状态中生效：主页、各面板显示自定义名称，话题页显示「话题名称 — 自定义名称」。保留完整话题名称，不误替换其中的分隔符或应用名文本。最多 120 个字符，失去焦点或按 Enter 保存；留空恢复原生名称。
- 服务端 Web 首帧标题也使用自定义名称。仅将应用名称与原生标题投射为公开启动元数据，不暴露完整配置。实验性 LiveShare 查看页无法读取宿主设置时使用页面加载时的名称快照，宿主改名后需刷新该查看页。独立登录插件不在处理范围内。
- 图片与设置保存在当前 DSH 宿主，连接同一宿主的浏览器共享；只读时禁止修改，保存失败会提示。停用插件时恢复原生 favicon 和标题，并撤销横幅样式和插槽。

## 安装

当前独立包版本为 **0.1.2**（2026-11-01）。此版新增主界面横幅及日夜独立的缩放、左右位移，沿用原有图片；此前 0.1.1 的 favicon 侧栏品牌标记继续保留。安装包包含已构建客户端，目标机器无需构建；未发布到 npm、未部署到用户实例。

将 `dsh-branding-0.1.2.tgz` 与同名 `.sha256` 转移到 DSH 机器，核对后安装；`web` 替换为实际 profile：

```sh
sha256sum -c dsh-branding-0.1.2.tgz.sha256
dsh plugin --profile web add /绝对路径/dsh-branding-0.1.2.tgz
```

重启 DSH、刷新网页，打开「设置 → 品牌设置」。从同名 `dsh-branding 0.1.0` 或 `0.1.1` 直接安装新版即可，已有图片、侧栏缩放、位移和应用名称设置保留，无需重新上传。新增主界面调整默认 100%／0px。首次安装时图片设置为空；其他品牌插件应先停用，不要同时启用两份品牌插件。

## 开发检查

```sh
npm test
npm run check
npm run check:compatibility
npm run check:browser
node scripts/check-hero-browser.mjs
```

检查在内存中编译客户端，不刷新发布文件。工作区需已有 jsdom、Puppeteer 与 Chromium，可通过 `DSH_BRANDING_BROWSER_EXECUTABLE` 指定浏览器路径。经用户授权后使用 `npm run build`、`npm pack` 并生成 SHA256 文件。

主界面浏览器检查使用两个固定版本的真实 Hero CSS、当前源码的内存 bundle 和现有 VCP Agent 样式，模拟两个独立会话的品牌／Agent 区域与插槽，不启动完整 dsh 或 Agent 网络服务。

固定核对 DSH `0.2.1-rc.2` 与 `0.2.2-alpha.2`，验证范围见 [COMPATIBILITY.md](COMPATIBILITY.md)。实际实例仍需确认：自定义 favicon 替换窄侧栏鲸鱼、悬停提示和展开点击正常、换图／清空及时生效、图片及标题设置持久化、默认中心避开按钮、日夜独立缩放和位移、话题／面板标题切换，以及停用后恢复原图与原生标题。
